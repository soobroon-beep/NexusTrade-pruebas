CRYPTOCHART — PROYECTO LISTO PARA GITHUB PAGES

1. Descomprime CryptoChart_GitHub.zip.
2. Crea un repositorio público en GitHub, por ejemplo cryptochart.
3. Sube TODO el contenido descomprimido. index.html debe quedar directamente en la raíz del repositorio, junto a assets y favicon.svg. No subas únicamente el ZIP ni solamente index.html.
4. En Settings > Pages, selecciona Deploy from a branch, rama main, carpeta /(root), y guarda.
5. Cuando GitHub termine, abre la dirección que muestra Pages.

No necesitas instalar programas ni compilar para publicar estos archivos.
index.html utiliza los archivos de assets, incluido el Worker de scripts.
Abre la aplicación desde la URL de GitHub Pages, no haciendo doble clic en index.html.

CÓDIGO FUENTE
codigo-fuente.zip incluye el proyecto editable, dependencias declaradas y archivo de bloqueo. No hace falta descomprimirlo para publicar.
Para modificarlo: descomprime ese ZIP en otra carpeta, instala Node.js 22 y ejecuta npm ci, npm run dev. Para generar una nueva publicación: npm run build. Sube el contenido de dist al repositorio.
